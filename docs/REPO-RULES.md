# Правила работы с репозиторием

**Строгие правила. Нарушение — повод для отката.**

1. **Вся работа — в отдельном worktree с отдельной веткой.**
   - Изменения делаются только через `git worktree add` + ветка вида `feat/<задача>` (или `fix/...`, `spike/...`), созданная от актуального `master`.
   - Основной чекаут (master) не используется для изменений, коммитов, сборок с модификацией.
2. **В `master` льёт только владелец (keroosha) — сам, либо по его явной просьбе.**
   - Агент НЕ коммитит в `master`, НЕ делает merge/fast-forward/`push` в `master` без явной просьбы.
   - По завершении работы: коммиты остаются в ветке worktree; владелец ревьюит и мёржит сам.
3. Работа считается законченной, когда изменения закоммичены в ветке worktree; слияние — ответственность владельца.
